# McKesson

[2020-01 → 2022-08]{.badge}

I joined [McKesson](https://www.mckesson.ca/en-CA/) in January 2020 as a software developer intern.

Day-to-day my work spanned:

- C# and VB.Net programming on the main software solution developed at McKesson.
- Winforms work via DevExpress.
- Support of clients made through investigative work and hot-fixing. (Database/Server/Network).
- Writing idempotent SQL script that need to be executed on multiple SQLServer versions (retro compatibility).
- Weekly addition of new Drugs/Compounds from [AQPP](https://www.monpharmacien.ca/en/aqpp/) (and possible fixes needed for encoding to work on our systems).
- Daily meeting with the Client Support team to collect feedback from clients and proactively act or fix issues.
- Database Architecture work (creating new tables, evaluating table performances and optimizing, etc...)

I also carried the conversion work, which is when a pharmacy would change their software licence from another competitor's to McKesson's.
This implied reverse engineering the data we received to match our database schema,
and then programming on a custom program that would map from the old software to ours (with the intent of losing no data and keeping traceability and auditing in check).

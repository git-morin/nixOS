## Things I made

- **Event streaming pipeline**: built a Kafka-based event streaming
  layer from scratch on [Benthos](https://www.benthos.dev/), with
  [Prometheus](https://prometheus.io/) metrics and Kubernetes-native
  deployment, and kept ownership of it since.
- **Data platform**: bootstrapped a [Databricks](https://www.databricks.com/)
  platform managed with [Pulumi](https://www.pulumi.com/) in
  [TypeScript](https://www.typescriptlang.org/), including scheduled
  data-consistency jobs and a natural-language data exploration space.
- **Monitoring**: stood up a [Splunk](https://www.splunk.com/) alerting
  project with dashboards and per-service alert configuration.
- **Team tooling**: founded a shared Claude Code plugin marketplace and a
  developer-environment Brewfile.
